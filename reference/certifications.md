# Certification Roadmap

Certifications are the cleanest way to turn studied knowledge into a **claimable** credential. Exam names, codes, prices, and retirements change often — **confirm on the official certification page before registering.**

*Verified: pending first weekly review.*

## Recommended path

Google Cloud is the primary target; one cert on another cloud shows multi-cloud range.

| Step | Certification | Why | Curriculum point |
|---|---|---|---|
| 1 | Google Cloud Digital Leader *(optional)* | Fast business-level baseline; useful vocabulary for customer conversations | After Phase 2 |
| 2 | **Google Associate Cloud Engineer** | Hands-on deploy/monitor/operate exam; the most credible first technical cert for a GCP role | After Phase 5 |
| 3 | Google Professional Cloud Security Engineer *or* a security cert on AWS/Azure | Directly matches security and CTI roles | After Phase 6 |
| 4 | **Google Professional Cloud Architect** | Standard credential for CE/solutions-architect roles | After Phase 8 |

## Equivalents on the other clouds

| Level | Google Cloud | AWS | Microsoft Azure |
|---|---|---|---|
| Foundational | Cloud Digital Leader | AWS Certified Cloud Practitioner | AZ-900 Azure Fundamentals |
| Associate admin/ops | Associate Cloud Engineer | AWS Certified SysOps Administrator – Associate | AZ-104 Azure Administrator |
| Architect | Professional Cloud Architect | AWS Certified Solutions Architect – Associate / Professional | AZ-305 Azure Solutions Architect Expert |
| Security | Professional Cloud Security Engineer | AWS Certified Security – Specialty | AZ-500 Azure Security Engineer / SC-200 Security Operations Analyst |

## Free, legitimate prep

- **Google Cloud Skills Boost** — official labs and learning paths for each Google exam
- **AWS Skill Builder** — official courses and some free labs
- **Microsoft Learn** — free official learning paths for every Azure exam
- The official **exam guide** for each certification — the authoritative list of what's tested

## Honesty note

Studying for a cert is not the cert. On a resume, list only certifications earned; "in progress" is fine in a cover letter or interview if it's true and has a target date.
